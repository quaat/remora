# Claude Code entry point

Read and follow `AGENTS.md` before working. Use `prompts/kickoff.md` for the first
session and `prompts/developer.md` for subsequent assigned tasks. Do not install
hooks or grant broader permissions automatically. Provider CLI flags and login
mechanisms must be checked against the installed tool's help before use.

Start by reporting the current task, blockers and verification commands; proceed
within the assigned scope. The bootstrap's human-operated workflow is not the
future autonomous Remora runtime.
